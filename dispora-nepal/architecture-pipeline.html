Saathi — Doc Scan & Visa Form-Fill Pipeline

Document Upload → Classify → Extract → Validate → Map → Fill → Human Review → Export

Pipeline Technology

  • • Claude Vision (Anthropic) — Devanagari + English OCR
  • • pdf-lib — AcroForm field population
  • • FastAPI — upload + extraction API
  • • Supabase — Postgres + Storage buckets
  • • Next.js PWA — bilingual review UI

Confidence Routing Rules

  • • ≥ 85% — auto-fill, green highlight, user can override
  • • 50–84% — pre-fill, amber, explicit confirm required
  • • < 50% — blank, red, user must type manually
  • • MRZ checksum + date plausibility cross-checks
  • • Never guess — low confidence always surfaces to user

Supported Documents

  • • Passport (MRZ extraction, checksum validation)
  • • Visa Grant Notice (subclass, dates, conditions)
  • • Payslips x1–3 (ABN, gross, employer name)
  • • Bank Statements (account, BSB, transactions)
  • • Birth Certificate (EN + Devanagari)
  • • Academic Transcript + English Test Result

Bilingual (EN / नेपाली)

  • • Source docs are English-language (passports, payslips)
  • • Review UI labels bilingual: "Passport Number / पासपोर्ट नम्बर"
  • • Tooltips in Nepali for unfamiliar form fields
  • • EN ↔ NP toggle in review UI settings
  • • Devanagari extraction supported (Nepali birth certs)
